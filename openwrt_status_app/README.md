# OpenWrt Status 移动端 App (Argon 主题版)

专为 OpenWrt 状态监控设计的现代化移动端应用，深度借鉴经典的 **LuCI Argon** 蓝紫毛玻璃磨砂主题风格，支持随时配置路由器的 IP、端口与 Token，提供极致丝滑的实时状态监控大屏。

---

## 亮点特性

- 🎨 **经典 Argon 主题美学**：Argon 蓝紫微霓虹渐变、毛玻璃磨砂卡片（Glassmorphism）、微边框与暗夜背景，带来高级质感。
- ⚡ **实时动态可视化**：
  - **CPU 处理器**：平均频率大字显示 + 4 核心独立频率动态柱状图。
  - **内存与温度**：实时百分比环/条形进度，冷暖色温动态映射。
  - **网络吞吐量**：双向 RX / TX 实时速率看板 + 双曲线平滑滚动动态流速折线图。
  - **在线设备列表**：区分 DHCP 租约设备与 ARP 邻居设备，展示 IP、MAC 与主机名。
- 🛠️ **灵活连接配置**：随时在右上角或底部点击打开设置抽屉，自由修改路由器 IP（预设 `192.168.6.88`）、端口（预设 `9090`）、Token 鉴权密钥及刷新频率（0.5s~5s）。支持即时连通性测试与 Ping 延时检测。
- 📱 **原生级移动体验 (PWA)**：支持直接在手机 Chrome / Edge / 微信等浏览器中打开并“**添加到主屏幕**”，无需安装繁琐应用商店包即可作为独立 App 全屏运行，无地址栏、支持离线缓存。

---

## 快速使用方法

### 1. 本地启动服务
进入 `openwrt_status_app` 目录并启动本地服务：

```bash
cd openwrt_status_app
npx serve -l 5173
```

或使用 npm 命令：
```bash
npm run dev
```

### 2. 在手机或电脑浏览器打开
- 电脑端调试：直接访问 `http://localhost:5173`
- 手机端体验：确保手机与电脑在同一局域网 Wi-Fi 下，用手机浏览器访问 `http://<你的电脑内网IP>:5173`

### 3. 在安卓手机上作为独立 App 使用
在手机浏览器菜单中选择：
👉 **“添加到主屏幕”** 或 **“安装应用”**
即可在手机桌面生成带有 Argon 专属路由图标的 App 图标，点击直接进入独立全屏界面！

## 打包为 Android 原生 APK (可选)

如需生成单独的 `.apk` 安装包，您可以在当前目录直接引入 Capacitor 或 Bubblewrap 打包：

```bash
# 1. 初始化 Capacitor
npx @capacitor/cli create

# 2. 添加 Android 平台
npx cap add android

# 3. 在 Android Studio 打开并编译生成 APK
npx cap open android
```
